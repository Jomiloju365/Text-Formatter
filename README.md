Text Formatter 📝

A simple, lightweight web app for transforming and analyzing text directly in your browser.

✨ Features

- Capitalize All — Converts text to uppercase.
- Reverse Text — Reverses the order of characters in your text.
- Remove Spaces — Removes spaces from the text.
- Text Statistics — Displays useful information about your text, including:
  - Word count
  - Character count
  - Space count

🛠️ Built With

- HTML
- CSS
- JavaScript

No frameworks or external libraries are required.

🚀 Getting Started

1. Clone the repository

git clone https://github.com/jomiloju365/text-formatter.git

2. Open the project

Navigate into the project folder:

cd text-formatter

3. Run it

Open "index.html" in your web browser.

That's it! 🎉

📂 Project Structure

text-formatter/
├── index.html
├── style.css
└── script.js

💡 How It Works

Enter your text into the text area, then select the formatting or statistics feature you want to use. JavaScript processes the text and updates the result directly on the page.

The app runs entirely in the browser, so your text doesn't need to be uploaded to a server.
